# DEADTAB

Static single-page browser experience for DEADTAB — the tab you forgot to close.

Open `index.html` in a browser, or serve the folder with any static host. Update future token and social details only in `data/config.json`.

## Navigation

- Click a browser tab to switch sections.
- Scroll beyond the top or bottom of a section to open the previous or next tab.
- On touch devices, swipe left/right (vertical swipe) or use the visible tabs.

Artwork is in `assets/images/`; the original uploaded images remain in the project root.
